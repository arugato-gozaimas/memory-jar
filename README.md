# Memory Jar

A digital keepsake — pull handwritten notes from a glass jar, one memory at a time.

## Develop

```bash
npm install
npm run dev
```

Set `VITE_MEMORIES_ENDPOINT` in `.env` to your Apps Script Web App URL (see `BUILD_PLAN.md`).

## Build

```bash
npm run build
npm run preview
```

See `PRD.md` for the product spec and `BUILD_PLAN.md` for setup notes.
